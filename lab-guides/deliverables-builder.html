How it's graded
  • Application of Concepts: the course's tools, used on Ascend IQ.
  • Credibility & Reasoning: every call backed by a number from your repo.
  • Clarity: a reader gets each slide in one pass.
  • Strategic Thinking: the trade-offs you made, and why.
Step 3

Download your presentation

One HTML file that opens in any browser. Use the arrow keys to move between slides. Submit it with your repo link on the Learning Platform within 7 days of your cohort ending.

If the download doesn't work here, click Copy the HTML, paste it into a new file named final-presentation.html, and save it. You can also commit it to your repo and turn on GitHub Pages.
